# TaskMate — AI-Powered Task Manager

TaskMate is a task management application with an AI assistant, FAQ support, error guidance, and support ticket management.

## Features

- Create, edit, complete, and delete tasks
- Filter tasks and view statistics
- AI assistant and FAQ support
- Error guidance and custom error pages
- Support ticket management
- Health check and request logging

## Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask
- Database: SQL and MongoDB
