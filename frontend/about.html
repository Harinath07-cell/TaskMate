About TaskMate

An AI-powered full-stack task management application developed for final project assessment.

🎯 Project Objective

TaskMate is designed to demonstrate proper full-stack software development practices in a maintainable, clean monolithic architecture. It provides an intuitive interface for managing personal tasks while featuring an intelligent grounded AI assistant that answers frequently asked questions, diagnoses HTTP errors, and generates support tickets.

✨ Core Features

  • Task CRUD Operations: Create, view, edit, complete, reopen, and delete tasks with priority levels and due dates.
  • Dynamic Dashboard Stats: Live calculations for Total, Pending, Completed, and Completion Percentage.
  • Intelligent FAQ System: Relational FAQ search and accordion interface powered by MySQL.
  • HTTP & Custom Error Guide: Deep explanations for HTTP 400, 401, 403, 404, 429, 500, 503, and DEV001 with interactive testing.
  • Grounded AI Assistant: AI chatbot powered by Groq API (Llama 3.3) with offline grounding fallback.
  • Support Ticket System: Automated ticket code generation (e.g. TKT-2026-XXXX) stored in MySQL.
  • MongoDB Audit Logging: Full trace conversation and feedback storage with graceful offline degradation.
  • External API Integration: Programming joke service with strict timeout and fallback safety.
  • Health Check & Request Logging: Structured logging and /health status endpoint.

🏗️ Architectural Overview

[Frontend Clients: Desktop / Tablet / Mobile (HTML5, Vanilla CSS, JS)]
                  │ REST JSON & CORS
                  ▼
[Flask Monolithic Backend Service (Python 3.11+, PyMySQL, PyMongo)]

      ├── MongoDB Document DB (Chat Logs, User Feedback)
      ├── External AI Service (Groq API Llama 3.3 / Gemini with local fallback)
      └── External Third-Party Joke API (with timeout & fallback)
